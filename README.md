# Mouse Varoluşsal Kriz Motoru

## Resmi Bilimsel Açıklama

Bu yazılım, bilgisayar mouse'’unun derin varoluşsal krizlerini bilimsel olarak modelleyen dünyanın en ciddi projesidir. Mouse artık "Ben kimim? Neden tıklıyorum? Tıklamak mı yoksa tıklanmak mı?" diye soruyor. Bu motor, mouse'’un ruhunu kurtarmaya çalışır ama başaramaz.

### Nasıl Çalışır?

- Mouse'’un tıklama yorgunluğunu hesaplar
- Rastgele felsefi krizler üretir
- "Ben gerçekten var mıyım?" sorusuna %0.0001 ihtimalle "evet" der
- Bürokrasi ile karıştırılmamalıdır (ama karışır)

### Kurulum

```bash
pip install -r requirements.txt  # aslında hiçbir şey yok
python mouse_kriz.py
```

### Uyarı

Bu programı çalıştırmak mouse'’unuzun varoluşsal krizini tetikleyebilir. Sorumluluk size aittir. Mouse'’lar sendikaya üye olabilir.
